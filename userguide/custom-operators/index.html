    Operators & Callbacks¶

    Custom operators¶

    Use an operator that is not in the standard list:

    Step 1 — register in the global registry (requires platform team approval):

    # config/operators/registry.yaml
operators:
  - name: MySpecialOperator
    import_path: plugins.special_ops.MySpecialOperator
    owner: my_team
    description: "Does the special thing"
    since: "1.0"

    Step 2 — declare in your project config:

    custom_operators:
  - name: MySpecialOperator
    import_path: "plugins.special_ops.MySpecialOperator"

    Step 3 — use in a task:

    tasks:
  - id: special_task
    operator: MySpecialOperator
    params:
      config_key: "value"
      threshold: 0.95

    The generator resolves the import and produces:

    from plugins.special_ops import MySpecialOperator

special_task = MySpecialOperator(
    task_id="special_task",
    config_key="value",
    threshold=0.95,
)

    Callbacks¶

    Callbacks are Python callables defined in your plugins/ or dags/ directory, referenced by their full dotted import path. The generator automatically adds the required from ... import ... statement.

    DAG-level:

    dags:
  - id: critical_pipeline
    on_failure_callback: "plugins.alerts.send_pagerduty_alert"
    on_success_callback: "plugins.metrics.record_dag_success"
    on_sla_miss_callback: "plugins.alerts.send_sla_warning"
    ...

    Task-level:

    tasks:
  - id: risky_task
    operator: PythonOperator
    on_failure_callback: "plugins.alerts.task_failed"
    on_retry_callback: "plugins.alerts.task_retrying"
    params:
      python_callable: "dags.pipeline.risky_step"

    Generated Python:

    from plugins.alerts import send_pagerduty_alert
from plugins.alerts import task_failed
from plugins.alerts import task_retrying

with DAG(
    ...,
    on_failure_callback=send_pagerduty_alert,
) as dag:
    risky_task = PythonOperator(
        ...,
        on_failure_callback=task_failed,
        on_retry_callback=task_retrying,
    )

    Note

    Callback import path format: module.submodule.function_name — the last dot-segment is the function name; everything before it is the module path.

    Standard operator reference¶

    These operators can be used without any registration. All module paths listed are the Airflow 3.x paths — they differ from Airflow 2.x (e.g. airflow.operators.bash → airflow.providers.standard.operators.bash). Generated imports always use the 3.x paths.

    Class name Airflow module Description
    BashOperator airflow.providers.standard.operators.bash Execute a bash command or script
    PythonOperator airflow.providers.standard.operators.python Call a Python callable
    EmptyOperator airflow.providers.standard.operators.empty No-op placeholder task
    DummyOperator alias for EmptyOperator (airflow.providers.standard.operators.empty) Deprecated alias for EmptyOperator
    BranchPythonOperator airflow.providers.standard.operators.python Branch based on the return value of a Python callable
    ShortCircuitOperator airflow.providers.standard.operators.python Skip downstream tasks when a Python callable returns False
    TriggerDagRunOperator airflow.providers.standard.operators.trigger_dagrun Trigger another DAG run
    HttpOperator airflow.providers.http.operators.http Execute an HTTP request (provider: apache-airflow-providers-http)
    S3ToRedshiftOperator airflow.providers.amazon.aws.transfers.s3_to_redshift Load data from S3 into Amazon Redshift (provider: amazon)
    S3CreateObjectOperator airflow.providers.amazon.aws.operators.s3 Create or overwrite an S3 object (provider: amazon)
    GlueJobOperator airflow.providers.amazon.aws.operators.glue Submit an AWS Glue ETL job (provider: amazon)
    SageMakerTrainingOperator airflow.providers.amazon.aws.operators.sagemaker Start a SageMaker training job (provider: amazon)
    EcsRunTaskOperator airflow.providers.amazon.aws.operators.ecs Run a task on Amazon ECS (provider: amazon)
    RedshiftSQLOperator airflow.providers.amazon.aws.operators.redshift_sql Execute SQL on Amazon Redshift (provider: amazon)
    GCSToGCSOperator airflow.providers.google.cloud.transfers.gcs_to_gcs Copy objects between GCS buckets (provider: google)
    BigQueryInsertJobOperator airflow.providers.google.cloud.operators.bigquery Execute a BigQuery job (provider: google)
    BigQueryCreateEmptyTableOperator airflow.providers.google.cloud.operators.bigquery Create an empty BigQuery table (provider: google)
    GCSDeleteObjectsOperator airflow.providers.google.cloud.operators.gcs Delete objects from a GCS bucket (provider: google)
    DataprocSubmitJobOperator airflow.providers.google.cloud.operators.dataproc Submit a job to a Dataproc cluster (provider: google)
    CloudRunExecuteJobOperator airflow.providers.google.cloud.operators.cloud_run Execute a Cloud Run job (provider: google)
    SparkSubmitOperator airflow.providers.apache.spark.operators.spark_submit Submit a Spark application (provider: apache.spark)
    KubernetesPodOperator airflow.providers.cncf.kubernetes.operators.pod Execute a task in a Kubernetes Pod (provider: cncf.kubernetes)
    SparkKubernetesOperator airflow.providers.cncf.kubernetes.operators.spark_kubernetes Submit a Spark application on Kubernetes (provider: cncf.kubernetes)
    KubernetesJobOperator airflow.providers.cncf.kubernetes.operators.job Create and run a Kubernetes Job (provider: cncf.kubernetes)
    KubernetesDeleteJobOperator airflow.providers.cncf.kubernetes.operators.job Delete a Kubernetes Job (provider: cncf.kubernetes)
    KubernetesPatchJobOperator airflow.providers.cncf.kubernetes.operators.job Patch a Kubernetes Job (provider: cncf.kubernetes)
    DockerOperator airflow.providers.docker.operators.docker Execute a command inside a Docker container (provider: docker)
    DockerSwarmOperator airflow.providers.docker.operators.docker_swarm Deploy and run a service in Docker Swarm (provider: docker)
    PostgresOperator airflow.providers.postgres.operators.postgres Execute SQL against a Postgres database (provider: postgres)
    MySqlOperator airflow.providers.mysql.operators.mysql Execute SQL against a MySQL database (provider: mysql)
    SqliteOperator airflow.providers.sqlite.operators.sqlite Execute SQL against a SQLite database (provider: sqlite)
    MsSqlOperator airflow.providers.microsoft.mssql.operators.mssql Execute SQL against Microsoft SQL Server (provider: microsoft.mssql)
    SnowflakeOperator airflow.providers.snowflake.operators.snowflake Execute SQL against Snowflake (provider: snowflake)
    DatabricksRunNowOperator airflow.providers.databricks.operators.databricks Run an existing Databricks job (provider: databricks)
    DatabricksSubmitRunOperator airflow.providers.databricks.operators.databricks Submit a one-time Databricks run (provider: databricks)
    EmailOperator airflow.operators.email Send an email notification
    SlackAPIPostOperator airflow.providers.slack.operators.slack Post a message to a Slack channel (provider: slack)
